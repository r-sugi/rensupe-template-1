# 写真の置き場所

このフォルダに写真を入れて main に保存（コミット）すると、ホームページに反映されます。

| ファイル名 | 表示される場所 |
| --- | --- |
| `hero.jpg` | トップの大きな写真（横長がおすすめ） |
| `facility-01.jpg` 〜 `facility-09.jpg` | 「スタジオと設備」の写真（縦横比 3:2 がおすすめ） |

- ファイル名は **半角小文字** にしてください（`.jpg` `.jpeg` `.png` `.webp` が使えます）。
- 写真を差し替えるときは、同じファイル名で上書きします。
- 1枚あたり **5MB以下** を目安にしてください（大きすぎると表示が遅くなります）。
- ファイル名を変えたり枚数を増やしたりするときは、`content/site.yaml` の `photos` と `hero_image_key` も合わせて書き換えます。
